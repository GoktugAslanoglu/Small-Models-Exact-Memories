# Original study records

This folder contains the original experiment implementation and archived
records for the 18-episode controlled matrix, LoCoMo-100, its controls, and
the exploratory ExactStrip / short-answer diagnostics.

The original `SUPPLEMENT_README.md` is preserved byte-for-byte as a historical
record. Its anonymous-submission wording, totals, commands, and description
of derived outputs describe the original archive, not the complete public
repository. Stale derived manuscript outputs and administrative revision
notes were excluded; `PROVENANCE.json` lists the selection.

For the final paper's scores and tables, use the numerical reconstruction
command in the repository-root README. The archived implementation and
runbooks are not guaranteed to operate in this relocated folder without
restoring their original relative paths and upstream dependencies. Missing
rendered pages, original model revision pins, and complete GPU journals are
not silently supplied by this release.
